# Rust Migration Phase 0 Dataset Definition

The original dataset definitions and measurement hashes below are historical.
As of 2026-10-28, shared data lives in [data/](../data/README.md), and generators
live in [tools/data_generation/](../tools/data_generation/). The regeneration
commands in section 8 use the current layout. `sample_waveform.parquet` is an
older optional fixture; the current small fixture is `test_100k.parquet`.

---

## 1. Purpose

To compare the Rust version's performance, rendering, and analysis behaviors, define representative datasets in three size classes: small, medium, and large. Large datasets are not kept under Git management; only their storage location or the steps to regenerate them are recorded.

## 3. Dataset Classes

| Class | Rough size | Candidates | Use | Git-tracked |
|-------|-----------|------------|-----|-------------|
| Small | 1k to 100k points | `sample_waveform.parquet`, `test_100k.parquet` | Fast checks during development | Not tracked as a rule. Existing files are kept for working purposes |
| Medium | Several million points | Synthetic data or real logs | Realistic feel checks | Not tracked |
| Large | ~90M-point class | Real logs or purpose-built synthetic data | Performance-limit checks | Not tracked |

- File name

- time range
- Ts / Fs
- File size
- Data origin
- Usage permissions

Creation policy:

- Prefer real logs when available
- If real logs cannot be used, generate synthetic data with the same row and channel counts
- Synthetic data must also include PWM, spikes, chirp, and noise

## 8. Regeneration Policy

Run from the repository root after the [tools setup](../tools/README.md#setup).
Outputs default to `data/`; add `--force` only when replacing existing files.

Small data:

```bash
python tools/data_generation/generate_test_data.py
```

Medium / large data:

- Use `tools/data_generation/generate_phase1_datasets.py`
- Parquet outputs are already excluded by the repository `.gitignore`

```bash
python tools/data_generation/generate_phase1_datasets.py medium
python tools/data_generation/generate_phase1_datasets.py large
```
