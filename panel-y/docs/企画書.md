## 3. Data Specification

### Panel_y's standard input format: Parquet

```
time（秒）, ch_name_1, ch_name_2, ...
0.000,      0.0,       0.0
0.001,      100.0,     5.0
```

- The column names are displayed as-is as channel names
- Metadata (units, sampling rate) is to be managed separately as JSON (planned)

### Supported input formats and preprocessing conversions

| Input format | Conversion | Notes |
|---------|---------|------|
| **Parquet** | Loaded directly | Standard format |
| **CSV** | `pandas.read_csv()` → `to_parquet()` | Bundled converter utility |
| **MATLAB .mat (≤ v7.2)** | `scipy.io.loadmat()` → `to_parquet()` | Bundled converter utility |
| **MATLAB .mat (≥ v7.3)** | `h5py` or `pandas.read_hdf()` → `to_parquet()` | Bundled converter utility |
