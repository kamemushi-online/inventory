## Decisions and Design Notes

- Interval statistics take the existing Cursor A/B as input
  - Consistent with the Phase 4 policy of routing analysis inputs through Cursor A/B
  - The same interval specification can be reused for statistics and the upcoming FFT
- The statistics target is restricted to `visible loaded channel`
  - Hidden channels are excluded since the user isn't currently viewing them
  - Unloaded channels are excluded because raw data is unavailable
  - Even when a single channel is displayed in multiple rows, its statistics appear on a single row
- A/B values use the sample nearest to each cursor time
  - Matches the approach in the Dash reference implementation
  - Interval statistics aggregate samples between the A/B nearest samples, inclusive on both ends
- Slope/s is computed as `(B - A) / (cursor_b - cursor_a)`
  - The sign of B-A is preserved even when the cursors are placed in reverse order
- The bottom panel is placed inside `CentralPanel` as a `Panel::bottom`
  - Lets the left side keep its vertical orientation while splitting only the central region vertically
  - Matches the user's requirement: "from the right edge of the left side panel to the right edge of the plot area"
- The statistics table separates the channel column from the numeric columns
  - With a plain horizontally scrollable table, the channel names disappear
  - Pinning the channel column and scrolling only the numeric columns is easier to read during measurement work
- The Cursor information panel was given both Hide and Collapse
  - Use Collapse when temporarily expanding the waveform area
  - Use Hide when returning to display work that doesn't need the analysis info

## Sticking Points and Resolutions

- Placing the statistics table on the left side ran out of horizontal space, and channel names disappeared during horizontal scrolling
  - Moved the statistics into the bottom panel and switched to a table with a pinned channel column
- `cursor_interval` is used in tests but not in normal builds, triggering a `dead_code` warning
  - Added `#[cfg(test)]` to exclude it from regular builds
- I didn't want the egui bottom panel range to overlap the left side panel
  - Reserved the left side first with `Panel::left`, then created the bottom panel inside `CentralPanel` — ordering matters
