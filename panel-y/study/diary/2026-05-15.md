## FFT Implementation Notes

- Following `study/fft_analysis_design.md`, added an FFT section to the Cursor information bottom panel in the Rust viewer.
- FFT computation uses `rustfft`, slicing the inclusive interval from the nearest indices of Cursor A/B.
- Target channels are taken from visible loaded channels, up to 3 at a time, with the first 3 selected by default.
- The FFT data-length limit is judged by the inclusive sample count of the Cursor A/B interval.
- The minimum is fewer than `4 samples/ch` (not executable); soft warning at `1,000,000 samples/ch` or above; hard limit at over `5,000,000 samples/ch` (not executable).
- Also not executable when estimated copy memory exceeds `384 MiB`. Maximum target channel count is `3 ch`.
- Supports Hanning / Hamming / Rectangular windows, Amplitude / dB scales, and frequency min/max display.
- FFT jobs run off the UI thread; stale job results are discarded by comparing `job_id` and the request key.
- `cargo check` and `cargo test` both pass. The FFT reference-value test compares against the Phase 0 reference when `test_100k.parquet` is available.
