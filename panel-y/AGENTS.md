# Codex Working Rules

This file contains the working rules for Codex. For rules aimed at Claude Code, see `CLAUDE.md`.

## Development Log

- When Codex is working, do not reference or edit `journal/`.
- Record development logs, work logs, and retrospectives in `study/diary/YYYY-MM-DD.md`.
- Treat `journal/` as a separately-managed area and do not touch it unless the user explicitly instructs you to.
