## Decisions & Design Notes

- Put the transient box-zoom state on `InteractionState`, not `ViewState`
  - Reason: in-flight drag state isn't display state that should be persisted in a session preset
- Folded box zoom into `handle_plot_interaction()`
  - The existing pan / zoom / reset all update `ViewState::x_range` in the same place, so we shouldn't scatter the responsibility for X-range manipulation
- An active box zoom can continue and commit even if the pointer leaves the plot rect
  - The existing code early-returns when the pointer is outside the plot rect, so the box-zoom update / finish logic is placed before that early return
- Skipped Y-direction box zoom this time
  - It would multiply the scope (per-row applicability, Auto/Manual toggle, reset behavior), which doesn't fit "low-risk improvements" of Phase 2.5
