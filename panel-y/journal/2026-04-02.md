## Decisions / design notes

- **Vectorizing `minmax_envelope`**: moved from the reshape approach (which truncated) to `reduceat` (no truncation). For fault-waveform review, dropping a tail peak is fatal, so this was the right call.
- **Handling non-monotonic time**: simpler to sort at load time than to keep a fallback path in the rendering code. The principle is: don't add branches to the hot path (`make_row_fig`).
- **Float32 down-cast**: keep the time column as float64 (for searchsorted precision); only convert signal channels to float32.

## Things that tripped me up

- `astype("float32", copy=False)` doesn't actually skip the copy for a float64→float32 conversion (the types differ, so a copy always happens). Worked around it with per-column in-place overwrite (PR#5).
