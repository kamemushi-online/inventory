## Decisions / Design Notes

- Reused the existing `ViewState::selected_row_id` for the Target row instead of introducing new state
  - `draw_target_row_selector()`, `draw_row_controls()`, and `load_selected_channel()` already read the same state, so the change stays narrow in scope
- Restricted hit-testing to within `plot_area_rect` rather than the whole row
  - Avoids the Target row changing unintentionally from clicks on label margins or gaps
- Drew the selection border last
  - Keeps the selection visible on top of grid / trace / hover-readout drawing
- Moved the `Rows` section to immediately after `Channels`
  - Lets the user confirm / change the target row right below the channel list when adding
  - `Session preset`, `View`, and `Cache` are auxiliary and were moved behind the main flow
