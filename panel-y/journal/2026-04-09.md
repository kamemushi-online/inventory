# Dev Journal - 2026-04-09

## What I did today

- Implemented the plot config save/load feature (Plot Config Save/Load) in `proto_3_1`

### What I implemented

**UI additions**
- Added a `.pyc.json` path input + 💾 (save) + 📂 (load) buttons to the header bar
- When loading a dataset, the matching `{data_name}.pyc.json` in the same directory is auto-suggested
- The path input shows completion candidates for directories and `.pyc.json` files (`list_config_suggestions`)

**Save (💾)**
- Serializes the current row definitions (channels, Y-axis range, step settings), channel styles (color, width), theme, and scroll-zoom setting as JSON
- Saved to the input path (defaults to the same directory as the data)

**Load (📂)**
- Reads the `.pyc.json` and auto-loads the referenced data file
- Restores row UI, channel styles, and waveforms in one shot (no need to click "Update")
- Theme and scroll-zoom state are also restored

**Code changes**
- Added `import json`
- `make_ch_settings(ch_list, ch_styles=None)` — added a style dict argument so colors/widths can be restored on load
- Added `list_config_suggestions()`
- New callbacks: `suggest_config_files`, `on_config_suggestion_click`, `save_plotconfig`, `load_plotconfig`
- Added the config-path auto-suggest output to `load_file` (8th Output)

### Plot config format (.pyc.json)

```json
{
  "version": 1,
  "data_path": "/path/to/measurement.parquet",
  "rows": [
    {"channels": ["ia", "ib"], "ymin": null, "ymax": null, "step_channels": []}
  ],
  "ch_styles": {"ia": {"color": "#1f77b4", "width": 1}},
  "theme": "dark",
  "scroll_zoom": false
}
```

## Decisions / design notes

- **FFT settings are intentionally not saved**: it's closer to a transient operation; configuring each time is fine
- **Loading also draws the waveforms in one shot**: `load_plotconfig` calls `waveform_row()` directly so you don't have to hit the "Update" button again after a load
- **Placement of `allow_duplicate=True`**: designed `update_waveform_rows` as the primary callback (no allow_duplicate), and `load_plotconfig` as the secondary (allow_duplicate=True)
